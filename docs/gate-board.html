Right now

v1.3.0 is published — tagged, pushed, and released on GitHub (2026-08-24) with the installer attached and its SHA-256 in the release notes. It shipped on a partial gate by owner ruling: 3 of 6 criteria run. Passed: strings audit on both the built and installed exe (all forbidden patterns zero; the sole updater hit is h2's next_window_update; both huggingface.co hits are the downloader manifest prefix and its error string), the NSIS install with the HKCU Run entry pointing at the installed exe, and functional EN + AR dictation into MS Word under 2 s. The repository is now confirmed public on GitHub (owner decision this session); post-release housekeeping is done — installer archived outside the repo with a verified hash, cargo clean run (10.5 GiB, no stray release exes).

What is not yet proven: the netstat loopback sampler, the firewall-block test, and the live-dictation functional checks were NOT RUN at ship time. The public release's zero-egress claim currently rests on the strings audit and compile-time deletions alone — the runtime half of the proof is owed. Compounding it: the v1.2.0 outbound-block firewall rules were found missing entirely during this cycle, so the standing firewall enforcement has been absent for an unknown period; recreating them needs an elevated shell.

No document-vs-repository contradiction stands: RELEASING.md's rule is a full pass per release, and the deviation is recorded there as a dated owner ruling with the exact run/not-run split, so the documents and the repository agree about what happened. One first-launch defect surfaced in acceptance testing and is recorded in ROADMAP.md: the silent startup window (hotkeys register only after the frontend loads; an early F9/F10 press is silently ignored).

Your next action

Close the owed half of the v1.3.0 gate: run the two New-NetFirewallRule commands in an admin PowerShell (they were provided in-session; the rules are currently missing), then say "start the sampler" and dictate for ~2 minutes so the netstat sample runs — followed by the under-block dictation + clean-download-failure check and the three live-dictation checks. Until then, the published release's runtime zero-egress proof is outstanding.
